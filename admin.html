🔐 تسجيل الدخول

اللوحة تحفظ التعديلات مباشرة بمستودع الموقع على GitHub، فتحتاج مفتاح دخول (Token) مرة وحدة بس على هذا الجهاز.

شلون تجيب المفتاح:
1. افتح صفحة إنشاء مفتاح بـ GitHub
2. Token name: اكتب kara-admin، وExpiration: اختار No expiration أو مدة طويلة
3. Repository access: اختار Only select repositories وبعدها Karar-TV
4. Permissions ← Repository permissions ← Contents: اختار Read and write
5. اضغط Generate token، انسخ المفتاح والصقه هنا
